# 名前の広東語（音声なし・試作）

姓と名を入力し、広東語の読みを千島式で表示する静的アプリです。元の普通話版は変更していません。

## 状態
- 7,536入力文字。これは既存の日本字体候補も含む入力キー数で、全字の読み・字体対応が人手確認済みという意味ではありません。
- 多音字・複数字体は未選択で赤字表示。変更は即時反映。
- 読みごとの日本語の意味を追加。全7,744候補中1,263候補、多音字などの候補159件中108件に収録（入力文字ごとの重複を含む）。未収録の意味は推測しません。音声は未収録です。
- CC-CEDICT Cantonese Readingsの漢字・普通話読み・広東語読みが一致するものに限り、既存CC-CEDICT日本語訳を結合。広東語独自の語義を網羅するものではなく、年代の異なる辞書を結合したため全件人手照合は未完了です。
- 千島英一氏の公開資料7.2の規則をもとに、授業の『ニューエクスプレス広東語』に合わせ長母音āはaaで表示（単独の長母音もaa）。『東方広東語辞典』の紙面との最終照合は未完了です。
- 未確認音節1件は推測せず除外。未知文字は残します。
- 名前を保存せず、外部APIへ送信しません。
- ブラウザで山田太郎の変換を確認。自動テスト12件成功。スマホ実機は未確認。

## 起動
`npm start` → http://127.0.0.1:5175/
配信用ファイルはdist/。ビルド不要。index.htmlの直接起動ではなくHTTPサーバーを使います。

広東語読み：CC-CEDICT Cantonese Readings、© 2015 Pleco Software Incorporated、CC BY-SA 3.0。
https://www.cc-canto.org/download.html
原データから単漢字項目を抽出。千島式に変換し、日本字体の候補へ結合。読みデータはCC BY-SA 3.0、CC-CEDICT由来の語釈・日本語訳・字体対応部分はCC BY-SA 4.0。各出典の条件を引き継いで配布。

字体候補：既存普通話版のCC-CEDICT / MDBG（CC BY-SA 4.0）とOpenCC（Apache License 2.0）由来の対応を利用。候補の広東語読みは別の広東語辞書で照合。普通話の読みは参考用として候補に表示します。意味は読み対応の一致を確認して結合したCC-CEDICTの英語語釈・日本語訳を使用（CC BY-SA 4.0）。英語原文は折りたたみ表示。自動翻訳項目は明記。
https://www.mdbg.net/chinese/dictionary?page=cedict
https://github.com/BYVoid/OpenCC

千島式規則の確認資料：千島英一氏の金沢大学公開資料、7.2「広東語の音韻体系と千島式ローマ字表記法」（本文20–21頁）。資料本文は配布物に同梱していません。
https://kanazawa-u.repo.nii.ac.jp/record/35631/files/SC-PR-CHISHIMA-E-%E6%9C%AC%E6%96%87.pdf

『東方広東語辞典』の本文・語釈・音声は複製していません。

「長」のzhang3→coeng4という元データの対応は、香港中文大学とCantoDictを照合しzoeng2に補正。英語語釈はCC-CEDICTから使用。

多音字の候補には、読み対応データで確認できる普通話の声調付きピンインを参考表示。複数の対応は併記し、候補の近くに一対一とは限らない旨を表示。

名前の字形は入力と同じ繁体字候補を優先（谷は谷のまま、穀を候補に出さない）。その候補がない場合は既存の字体対応を使用。候補が複数で未選択なら結果の漢字は元の字を保持し、選択後に変換。
